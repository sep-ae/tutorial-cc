Deploy with
Docker & Cloud

Dokumentasi lengkap deployment web menggunakan Docker, Portainer, Nginx Proxy Manager, dan Cloudflare DNS pada dual VPS infrastructure.

Proyek ini merupakan tugas akhir mata kuliah Cloud Computing yang berfokus pada implementasi containerization dan deployment aplikasi web pada infrastruktur cloud. Setiap anggota kelompok men-deploy website portfolio masing-masing ke dalam Docker container yang berjalan di dua VPS (Virtual Private Server) yang saling terhubung melalui Portainer Agent. Traffic di-manage menggunakan Nginx Proxy Manager sebagai reverse proxy dengan SSL certificate dari Let's Encrypt, dan domain routing dikonfigurasi melalui Cloudflare DNS. Seluruh proses deployment terintegrasi dengan GitHub repository untuk continuous deployment.

Roadmap

Deployment Journey

Step-by-step perjalanan deployment dari instalasi Docker hingga HTTPS live.

Step 01

Install Docker

Langkah pertama adalah menyiapkan environment dasar dengan menginstall Docker Engine pada VPS. Proses ini menggunakan script instalasi resmi dari Docker agar mendapatkan versi stabil terbaru secara otomatis. Setelah terinstall, user default dimasukkan ke dalam grup docker agar kita dapat menjalankan berbagai perintah Docker tanpa harus selalu menggunakan hak akses sudo (root).

bash
sudo apt update && sudo apt upgrade -y curl -fsSL https://get.docker.com | sh sudo usermod -aG docker $USER newgrp docker docker --version
🐳
Step 02

Install Portainer

Setelah Docker berjalan, kita mendeploy Portainer CE (Community Edition). Portainer berfungsi sebagai Graphical User Interface (GUI) berbasis web yang sangat canggih. Alat ini memudahkan kita memantau resource, melihat log, dan mendeploy container tanpa perlu mengetikkan perintah rumit di terminal. Dashboard manajemen ini dapat diakses secara aman melalui port 9443.

🖥️ VPS A Portainer

Buka VPS A ↗

🗄️ VPS B Portainer

Buka VPS B ↗
bash
docker volume create portainer_data docker run -d \ --name portainer \ --restart=always \ -p 9443:9443 \ -p 8000:8000 \ -v /var/run/docker.sock:/var/run/docker.sock \ -v portainer_data:/data \ portainer/portainer-ce:lts
📦
Step 03

Install Portainer Agent

Karena arsitektur kita melibatkan lebih dari satu server fisik, kita perlu menginstall Portainer Agent di VPS sekunder (VPS B). Agent ini bertugas sebagai jembatan komunikasi sehingga VPS utama (VPS A) dapat mendeteksi, mengendalikan, dan mendeploy container ke VPS B, semuanya dilakukan terpusat hanya dari satu layar dashboard Portainer di VPS A.

bash
docker run -d \ --name portainer_agent \ --restart=always \ -p 9001:9001 \ -v /var/run/docker.sock:/var/run/docker.sock \ -v /var/lib/docker/volumes:/var/lib/docker/volumes \ -v /:/host \ portainer/agent:lts
🔗
Step 04

Install Nginx Proxy Manager

Nginx Proxy Manager (NPM) diinstal menggunakan Docker Compose untuk bertindak sebagai pintu masuk utama atau Reverse Proxy. NPM menerima semua traffic pengunjung (port 80/443) lalu meneruskannya secara akurat ke container milik masing-masing anggota kelompok berdasarkan subdomain. NPM juga dilengkapi antarmuka web memukau untuk mengurus sertifikat SSL Let's Encrypt secara otomatis.

docker-compose.yml
version: '3' services: npm: image: jc21/nginx-proxy-manager:latest restart: unless-stopped ports: - "80:80" - "81:81" - "443:443" volumes: - ./data:/data - ./letsencrypt:/etc/letsencrypt
bash
docker compose up -d
🔀
Step 05

Buka Port yang Diperlukan

Untuk memastikan semua layanan container dapat diakses dengan lancar dari internet, kita wajib mengatur Firewall (Security Group) pada panel kontrol cloud provider (VPS). Port esensial yang dibuka meliputi HTTP/HTTPS (80, 443), antarmuka manajemen Portainer (9443), port komunikasi Portainer Agent (9001), dan port admin NPM (81).

Step 07

Deploy dari GitHub

Di sinilah kehebatan fitur GitOps pada Portainer bekerja! Kita tidak perlu memindahkan file source code (HTML/CSS/JS) secara manual via FTP ke server. Cukup salin URL repositori GitHub kita dan masukkan ke dalam menu Stacks di Portainer. Portainer akan secara otomatis mengunduh kode terbaru dari branch GitHub kamu, lalu mengeksekusi docker-compose.yml untuk membangun container. Jika ada update kode di GitHub di kemudian hari, Portainer bisa disetting agar me-redeploy web kita secara instan!

Repository URL
https://github.com/sep-ae/sep-ae.github.io.git
Compose Path
docker-compose.yml

Stacks → Add Stack → Repository → Deploy Stack

🐙
Step 08

Dockerfile & Compose

Dockerfile: Digunakan untuk membungkus (package) file HTML/CSS/JS web statis ke dalam image Docker berbasis ringan nginx:alpine.

Dockerfile
FROM nginx:alpine COPY . /usr/share/nginx/html EXPOSE 80

docker-compose.yml: Digunakan untuk mendefinisikan dan menjalankan container. Di sini kita menetapkan nama container tutorial dan memetakan port 3005 di VPS ke port 80 di dalam container.

docker-compose.yml
version: '3' services: septito-web: build: . container_name: tutorial ports: - "3005:80" restart: unless-stopped
📄
Step 09

Cloudflare DNS & NPM Config

Langkah pamungkas agar web portofolio dapat diakses menggunakan domain adalah konfigurasi DNS. Kita menambahkan A Record di Cloudflare yang mengarah ke IP publik VPS kita. Setelah domain aktif, langkah akhirnya adalah menambahkan "Proxy Host" baru di dashboard Nginx Proxy Manager. NPM akan membaca subdomain yang diminta pengunjung (misal: septito...), lalu membelokkan lalu lintas tersebut langsung ke port lokal (misal: 3005) dari container Docker milik kita secara aman.
